# Conversion roadmap

The codebase started as SerboTalk, a Russian/English → Serbian trainer running on OpenAI. It is being converted to a Turkish trainer running on Claude and ElevenLabs. "Planned (Phase N)" in the views refers to these phases.

| Phase | Outcome | Status |
|---|---|---|
| 0 | Architecture documentation and agent guardrails (this directory, `AGENTS.md`, `CLAUDE.md`, agent sandbox, secret scanning) | Done |
| 1 | Tooling baseline: `uv` + lockfile, Ruff, Pyright, Biome, pinned frontend dependencies, `justfile`, GitHub Actions, architecture checks | In progress: backend done; frontend pending |
| 2 | Claude and ElevenLabs adapters behind the provider ports; usage ledger; budget guard with a $25 monthly cap on every AI entry point | Done in the backend, tested with fakes; live providers not yet exercised. Client "practice paused" message done for answer check, speech-to-text and review-phrase preparation. Custom topic creation too, since ADR-0008 added the failure reason to its error |
| 3 | Turkish language: text policy, prompts, `_sr` → `_tr` rename, re-authored content, grading eval | In progress: text policy, prompts, rename, OpenAI removal and Turkish content (210 phrases, hints, 50 skills, fallback exercises) done; native-speaker review of the content and the grading eval pending (eval needs provider keys, run before deployment). The Turkish product starts from a fresh database: `seed` refuses a database that holds skills from the Serbian catalogue |
| 4 | Frontend restructure: Tailwind v4 tokens, shadcn/ui, TanStack Router and Query, i18next, `App.tsx` split by feature | In progress: Serbian alphabet toggle removed (`serbianScript.ts` replaced by `turkishText.ts`), budget-paused message, mocked e2e spec repaired, green locally and a required CI job. Tailwind v4 with design tokens and shadcn/ui components in `src/shared/`; the inherited stylesheet sits in a lower cascade layer and shrinks screen by screen; Settings migrated; practice screen extracted into `features/practice/` and redesigned in the tea-house world (Impeccable critique, roll and finish review; ADR-0003 amendment); app shell (headers, topic chooser, welcome and completion states) moved to `features/shell/` on the tokens, and every colour left in the legacy stylesheet mapped onto the tokens, so the remaining legacy screens render in the tea-house palette too. Statistics moved to `features/statistics/` on the tokens. Premium and the custom topic and phrase forms moved onto the tokens and shared Input/Select/Field components. Settings sub-sections, the admin pages, the login card and the legal pages followed. The payment form (reworked with the payment country in Phase 5), the reward overlay and the landing page still use legacy CSS; routing, data layer, i18next and the rest of the `App.tsx` split not started |
| 5 | Rebrand to the working name TurkTalk and move to the owner's own infrastructure | Not started |
| 6 | UX verification with the Impeccable skill, accessibility checks and screenshot baselines | Not started |

Update the Status column as phases land.
